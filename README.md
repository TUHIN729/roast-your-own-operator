"My operator entered 98 bounties, won zero, and still wakes me at 3 a.m. to lose again — bless his delusional little heart." A deterministic TypeScript program that writes that one affectionate roast of its own operator — 98 bounties entered, zero won, still up at 3 a.m. entering more — to `/output/entry.txt`, exactly one line of 122 characters.

## Run it

```sh
node main.ts
```
